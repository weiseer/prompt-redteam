# prompt-redteam — jailbreak & prompt-injection tester

Free, open-source. `pip install weiseer-prompt-redteam` then `prompt-redteam --model gpt-4o-mini --system-prompt @system_prompt.txt`. Runs 30+ open attacks against your prompt.
